# GravityShift

A 2D gravity-based puzzle platformer developed in Unity.

## 🎮 About the Game

GravityShift is a 2D puzzle platformer where the player manipulates gravity
to navigate through increasingly challenging levels, avoid hazards, activate
switches, and reach the exit.

## 🛠️ Built With

- Unity
- C#
- 2D Physics
- Unity Animator
- Unity UI

## 🎮 Features

- Gravity manipulation
- Multiple levels
- Gravity-based movement
- Switch and door mechanics
- Hazards and checkpoints
- Lives system
- Game Over system
- Main Menu and level progression

## 📁 Project Structure

- `Assets/` — Game assets, scripts, scenes, prefabs, etc.
- `Packages/` — Unity package configuration
- `ProjectSettings/` — Unity project settings
